# Browse DAOs

The Atlas DAO directory helps you discover indexed organizations, search by name, and compare governance activity. Market-rank and activity signals help organize a large directory without implying that market capitalization measures governance quality.

Open a DAO to inspect proposal activity, data availability, recent governance, votes, voters, discussions, and timelines. `hasVoteData` and `hasForumData` indicate whether those specialized views are available.
