# DeGov Atlas

Atlas is DeGov's public governance intelligence application. It turns indexed onchain and offchain activity into navigable DAO, proposal, vote, voter, discussion, and signal views.

[Open Atlas](https://atlas.degov.ai)

Atlas is public to browse. Its server uses protected backend routes that are not a public partner API; integrations should use the [Agent API](../agent-api/index.md).
