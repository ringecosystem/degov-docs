# Guides

| Goal | Start with | Tier |
| --- | --- | --- |
| Find active proposals | Proposal list | standard |
| Resolve a URL, title, or external ID | Proposal resolve | standard |
| Follow important governance updates | Events or signals | standard |
| Explain vote results or concentration | Vote summary, then vote rows | plus |
| Research voter activity | DAO voter ranking, then profile/history | plus |
| Browse governance discussions | Forum topic list, then detail | standard / plus |
| Build an auditable brief | Proposal detail plus evidence | plus |

Use free DAO discovery first, narrow candidates with standard resources, and fetch plus resources only when they improve the answer.
